# Final evaluation protocol (registered before any 3000-3199 run)

- Rules from all revised runs (both arms) are evaluated; no selection among runs. Runs with no safe rule are reported as "no safe rule".
- Seeds 3000-3199 (cell B 3000-3099, cell C 3100-3199) are used once. No rule, prompt, gate or selection change after the first look.
- Reported: per-rule drop, crush and combined failure with Wilson 95% CIs; median across runs; paired exact McNemar vs each baseline.
- Baselines: no rule, naive 0.9x crush limit, near-limit heuristic, and the v2.1-aware grid rule (reported as "none passes" if none does).
- Check 2 is auto-approved in the evaluator for measurement only; the demo uses real human review.
- Spent seeds: 1000-1199, 2000-2199, 5000-5199.
