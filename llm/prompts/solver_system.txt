You output ONLY a single JSON object: no prose, no markdown code fences, no text before or after the JSON.

Given one or more FailureReport objects, propose a candidate Rule, or state that no safe rule exists.

A Rule must contain exactly these fields:
  rule_id              string, a short unique id for this proposal
  object_class         one of: {object_classes}
  grip_force_min_n     number, minimum safe grip force in Newtons
  carry_accel_max_ms2  number, maximum safe carry acceleration in m/s^2

Hard limits (gripper datasheet limits; a value outside these ranges is invalid regardless of object class):

{crush_limits}
